## F1 — suite tooling → `handrolled` (user-selected option)

Hand-rolled invariant suite, zero new dependencies. Checks ride the existing
fake-DOM surface harnesses plus static CSS/markup audits. Rationale recorded in
the fork: the §7.5 dependency diet (≤5 pinned deps, audited) is itself a
release gate; axe-core + jsdom would violate it without a dependency amendment.
Diet is pinned as a tripwire test (checklist-sync: axe-core/pa11y/jsdom/
happy-dom/domino must never appear in package.json).

## F2 — lane → `unit lane, included in pnpm test` (user-selected option)

`ops/tests/a11y/**/*.test.ts` joins the vitest `unit` project include — the
zero-defect gate stays cheap and mandatory on every `pnpm test`. No separate
long-running lane; no CI yaml churn beyond the include glob.

## F3 — remediation → `remediate inside E7-T03` (user-selected option)

Fix-forward in the same unit as the suite (surface-law attributes + CSS mode
blocks, no architectural change). Landed:

- `assets/surfaces.css`: `@media (prefers-contrast: more)` (borders thicken,
  focus ring 3px, `--l-line` strengthens) + `@media (forced-colors: active)`
  (defer to system palette — ButtonBorder, Highlight; pressed state stays
  distinguishable via aria-pressed + Highlight with system colors, never a
  hard-coded paint-over).
- `entrypoints/workroom/index.html`: `lang="en"` added (document-language
  honesty; offscreen doc gets no viewport/noscript — it is never displayed,
  and the suite encodes that distinction).

## What the new suite pins (23 proofs, all green)

- `keyboard.test.ts` — overlay arrows drive `aria-activedescendant` with bounds
  clamping (re-query law: the palette re-renders per move); enter activates the
  arrowed selection (kept hit → ResumeMission); escape closes; guardian/quiet
  undo (`u`, `ctrl+z`) and refresh (`r`) combos fire from the page; the
  allowInInput law — typing `u` inside a field never fires a surface command
  (prose is sacred).
- `contrast-zoom.test.ts` — the two new mode blocks exist, thicken borders/
  focus, defer to system colors, and follow reduce-motion (one mode family);
  zoom integrity as the rem law (no `max-width: Npx`, no wide fixed widths, at
  most one absolute font-size token); `:focus-visible` ring; shells carry
  lang/title (+viewport/noscript on user-visible surfaces).
- `heartbeat.test.ts` — `role=status` + stable catalog aria-label; zero-count
  is the honest quiet copy (never a fake "all safe"); updates re-announce;
  labels never carry volatile counts.
- `checklist-sync.test.ts` — doc ↔ suite ↔ diet stay in lockstep.
